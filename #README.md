# 🚀 AgentVerse - AI Powered Productivity Assistant

AgentVerse is an AI-powered productivity assistant built as a Chrome Extension that helps students and professionals manage their studies, tasks, schedules, and focus sessions using a multi-agent architecture.

It combines Artificial Intelligence with productivity tools like Google Calendar, Notion, Spotify, and browser activity tracking to provide an intelligent study companion.

---

## 🌟 Features

### 🤖 AI Chat Assistant
- AI-powered conversational interface
- Study assistance
- Instant doubt clarification
- Personalized responses

### 📅 Smart Planner
- AI-generated study schedules
- Daily and weekly planning
- Calendar integration
- Task prioritization

### 📖 AI Tutor
- Explains concepts
- Answers academic questions
- Generates study suggestions
- Learning assistance

### ⏱ Focus Tracker
- Tracks browser focus time
- Productivity monitoring
- Session analytics
- Focus statistics

### 🎵 Spotify Integration
- Connect Spotify account
- Play/Pause music
- Study playlist support
- Current song information

### 📝 Notion Integration
- Save notes automatically
- Organize study material
- Manage productivity workspace

### 📆 Google Calendar
- Create study events
- Schedule reminders
- View upcoming events
- Time management

### 📊 Analytics Dashboard
- Productivity score
- Task completion
- Daily streak
- Study insights
